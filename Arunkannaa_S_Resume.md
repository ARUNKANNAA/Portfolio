## PROJECTS

**Aid for All – Smart Assistive Monitoring & Emergency Support System**
Developed an IoT-based assistive healthcare system for elderly people, wheelchair users, and patients requiring continuous monitoring. Integrated fall detection, GPS tracking, voice assistance, remote alerts, and caretaker communication using RTOS, internal web server, and AP-mode Wi-Fi configuration.
*Technologies:* ESP32, MPU6050, DHT11, AI Thinker GPS Module, JQ6500, Twilio, RTOS, SolidWorks, 3D Printing

**AI-Based Smart Assistive Wearable for Alzheimer's Patients**
Developed a wearable smart assistance system using Raspberry Pi and computer vision to help Alzheimer's patients recognize people, receive reminders, and improve safety. Implemented face recognition, audio assistance, caregiver alerts, geofencing, and wearable removal detection.
*Technologies:* Raspberry Pi, Camera Module, Flask, Face Recognition, Audio Output, Twilio SMS

**Nitroasis – AI Powered Smart Farming System**
Built an AI-driven smart agriculture system using IoT, TinyML, automation, and local AI assistance. Implemented real-time monitoring of environmental parameters and crop prediction using Edge Impulse TinyML on ESP32.
*Technologies:* ESP32, DHT11, Soil Moisture Sensor, LDR, OLED Display, Streamlit, Ollama, Llama3, TinyML, RTOS

**Twinkle – Interactive Desktop Companion Robot**
Designed and developed an interactive companion robot with animated facial expressions, touch interaction, audio feedback, focus timer, mini games, and Wi-Fi setup portal.
*Technologies:* ESP32-C3 SuperMini, SH1106 OLED, JQ6500, Speaker, Capacitive Touch, NTP Server

**Smart Helmet Safety System**
Developed a smart helmet system for rider safety with accident detection, drowsiness monitoring, alcohol detection, and GPS-based emergency alerts.
*Technologies:* ESP32, MPU6050, IR Sensor, MAX30102, GPS Module, Alcohol Sensor, Twilio

**ESP32-CAM Wireless Streaming System**
Developed a wireless live-streaming surveillance system using ESP32-CAM with AP mode connectivity and RTOS-based task management for real-time video streaming and image capture without internet connectivity.
*Technologies:* ESP32-CAM, External Antenna, RTOS, IP5306, Battery System

**Smart Home Automation for Fishes**
Designed a smart aquarium automation system with Bluetooth-based remote monitoring, automated feeding, and automated water maintenance.
*Technologies:* Arduino Uno, HC-05 Bluetooth Module, Stepper Motor, Water Pump, Relay Module

**Automated Solar Monitoring & Cleaning System**
Developed an ESP32-based solar panel monitoring and automated cleaning system with real-time sensor monitoring and servo-controlled cleaning mechanism.
*Technologies:* ESP32, MG995 Servo, Light/Color Sensor, Web Dashboard
